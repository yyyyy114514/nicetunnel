# 部署说明

## Pages（上报实例）

1. 在 Cloudflare 控制台创建 Pages 项目，选择“直接上传”。
2. 上传本 zip，或将 zip 解压后上传整个目录。
3. 在“设置 → 环境变量”中设置 `UUID`（站点标识；多个实例部署时保持一致）。
4. 按需绑定自定义域名。上报实例不需要绑定 KV。

## Workers（主实例）

1. 创建 Worker，将 `_worker.js` 内容粘贴到编辑器；也可使用 `wrangler.toml` 部署。
2. 绑定 KV 命名空间，绑定名必须为 `KV`（存放检测历史）。
3. 配置 `ADMIN`（面板密码），并按需配置 `KEY`、`HOST`。
4. 配置定时触发器 `*/5 * * * *`（检测周期），再绑定自定义域名。

## 环境变量

| 变量 | 用途 |
|---|---|
| `UUID` | 站点标识，多实例部署时保持一致 |
| `ADMIN` | 面板密码（主实例） |
| `KEY` | 面板快捷访问路径 |
| `HOST` | 对外主机名 |

部署完成后先访问状态页确认实例在线，再在面板里添加检测目标。升级时保留原有环境变量与 KV 绑定。
