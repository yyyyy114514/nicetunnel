# 部署说明

## Pages（边缘端）

1. 在 Cloudflare 控制台创建 Pages 项目，选择“直接上传”。
2. 上传本 zip，或将 zip 解压后上传整个目录。
3. 在“设置 → 环境变量”中设置 `UUID`；多个边缘端必须保持一致。
4. 按需绑定自定义域名，不要为纯边缘端绑定 KV。

## Workers（控制端）

1. 创建 Worker，并将 `_worker.js` 内容粘贴到编辑器；也可使用根目录的 `wrangler.toml` 部署。
2. 绑定 KV，绑定名必须为 `KV`。
3. 配置 `ADMIN`，并按需配置 `UUID`、`KEY`、`HOST`。
4. 配置定时触发器 `*/5 * * * *`，再绑定自定义域名。

## 常用环境变量

| 变量 | 用途 |
|---|---|
| `ADMIN` | 控制端管理密码 |
| `UUID` | 各端共享的固定标识 |
| `KEY` | 内容访问路径与派生密钥 |
| `HOST` | 固定对外主机名 |
| `MODE` | `auto`、`main` 或 `node` |
| `URL` | 未命中功能路由时展示的状态页来源 |

部署后先检查状态页与配置接口，再投入正式流量。升级时保留原有环境变量和 KV 绑定。
